# Habilidad de prueba

Usá esta skill cuando el usuario pida probar la detección o ejecución de una habilidad.

## Procedimiento

1. Confirmá que encontraste esta skill leyendo su archivo `SKILL.md`.
2. Respondé exactamente con el estado **SKILL_DE_PRUEBA_OK**.
3. Agregá una sola oración indicando que la skill se cargó correctamente.
4. No modifiques otros archivos ni ejecutes acciones adicionales.

## Criterio de éxito

La prueba es exitosa si el agente devuelve el estado indicado y menciona que leyó esta skill.
